# Changelog

## 0.4.0 - 2026-09-30
- Premium multi-page dashboard with Dashboard, Job Hunting, Application Center and AI Agent.
- Live clock/date/year display with online status indicator.
- Live public job-feed search with keyword and location filtering.
- Job-hunting workflow for remote and location-based listings.
- AI CV/ATS and cover-letter generation shortcuts.
- Application Center with reviewed email handoff; user confirms the final recipient and send action.
- New Mazkiplay Agent launcher icon.
- AI system prompt upgraded for career and application workflows.
